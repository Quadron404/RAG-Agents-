Report the actual state of interactive cards, agent orchestration, Team, persistent identities, avatar system, retrieval/memory, Computer, Files, security, and performance. Include exact files, schema changes, API contracts, test commands/results, deployed Worker version, source SHA mapping, and unresolved limitations. Separate implemented, tested, integration-tested, and production-verified features; never claim completion without evidence.

MANDATORY EXECUTION
Start by checking the current main SHA and confirming the relevant paths exist. Read the implementation, callers, types, tests, migrations, configuration, and runtime contracts before editing. Trace the complete path from the user action to the authoritative backend operation and persisted result. Implement the smallest integrated root-cause change that satisfies this mission; reuse existing services and contracts wherever they are sound. Add regression tests for normal behaviour, invalid input, failure, concurrency, owner isolation, and recovery as applicable.

ENGINEERING CONSTRAINTS
Do not create a parallel subsystem, duplicate state store, fake UI activity, arbitrary model-controlled permissions, or a second source of truth. Keep secrets server-side. Do not weaken authentication, approval, idempotency, retention, or restricted-computer boundaries. Do not deploy or perform irreversible production actions without explicit authorization. If a required external configuration is missing, fail closed and report the exact missing item.

ACCEPTANCE AND REPORT
Demonstrate the real behaviour with source-level evidence and executed tests. Report exact files changed, schema/API compatibility, commands run, pass/fail counts, preserved features, deployment status if authorized, and remaining limitations. If already implemented, prove it and make no unnecessary rewrite.
