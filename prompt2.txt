COMPULSORY REPAIR LOOP — REPEAT UNTIL PASS
For EACH defect and EACH failing acceptance criterion:

2. Capture before evidence: screenshot, DOM/accessibility evidence, console errors, failed network requests and Browserless session/run ID when available.
3. Trace the real root cause through React state, API contract, Worker route, D1 query/migration, backend/Codespace service or provider integration. Do not guess from appearance.
4. Implement the complete fix at the correct layer. Do not hide the defect with CSS, mock data, optimistic-only state or swallowed errors.
5. Add a regression test at the lowest useful layer plus an integration/contract test where applicable.
6. Run focused tests, full relevant suite, typecheck and production build.
7. Deploy changed frontend assets AND Worker to the existing Cloudflare deployment using the AI7 environment secret CLOUDFLARE_API_KEY. Never print, log, paste, copy into code or commit the secret. Verify Wrangler's supported environment credential mechanism; never guess a flag or secret variable.
8. Open the deployed production URL again through the SAME Browserless MCP. Repeat the exact failing scenario and adjacent regression scenarios at desktop and mobile breakpoints.
9. If anything still fails, return to step 1. Repeat reproduce → root-cause fix → tests → deploy → Browserless retest until all acceptance criteria pass.
10. Mark the prompt complete only when the deployed flow passes with evidence. If an external dependency (Browserless outage, OAuth configuration, provider outage, unavailable Codespace) blocks the loop, document the precise blocker and mark BLOCKED, never PASS. Continue independent safe test cases.
